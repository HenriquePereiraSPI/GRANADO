<granado-chart-bar>

Gráfico de barras em SVG (Light DOM, estilos inline). Suporta barras simples, agrupadas, empilhadas, empilhadas 100% e target (faixa mín→máx), na vertical ou horizontal, com legenda, grade, tooltip, rótulos de valor, animação, meta global e exportação PNG/CSV. Cores padrão da paleta Granado (validada p/ legibilidade e daltonismo) e layout responsivo.

Import

<!-- Inclua o script no <head> (padrão Apriso) -->
<script src="[AprisoScripts]/WebComponents/granado-chart-bar.js"></script>

Uso — via script (recomendado)

Defina xField, yFields e data por propriedade (aceita objetos/funções).

<!-- Import (no <head>) -->
<script src="[AprisoScripts]/WebComponents/granado-chart-bar.js"></script>

<granado-chart-bar id="d-basic" title="Vendas por mês" show-values="true"></granado-chart-bar>
<script>
  var c = document.getElementById('d-basic');
  c.xField = 'month';
  c.yFields = [{ field: 'sales', label: 'Vendas' }];
  c.data = [
    { month: 'Jan', sales: 120 }, { month: 'Fev', sales: 180 }, { month: 'Mar', sales: 150 },
    { month: 'Abr', sales: 220 }, { month: 'Mai', sales: 200 }, { month: 'Jun', sales: 260 }
  ];
</script>

Uso — declarativo (HTML)

data e y-fields também aceitam JSON por atributo (aspas simples). Útil quando nenhuma série usa funções (formatter/tooltipFormatter).

  data='[{"month":"Jan","sales":120,"target":150},{"month":"Fev","sales":180,"target":160},{"month":"Mar","sales":150,"target":170}]'></granado-chart-bar>

Tipos — type

O type define o layout das séries; as séries vêm das yFields (formato largo) ou do x2Field (formato longo). grouped com 1 série parece simple (não há o que agrupar).

typeO que faz
simpleUma barra por categoria (usa a 1ª série).
groupedSéries lado a lado dentro de cada categoria.
stackedSéries empilhadas (soma por categoria).
stacked100Empilhadas normalizadas a 100% (participação).
targetBarra flutuante de faixa: usa 2 campos [min, max].

2º agrupador — x2Field

xField é a dimensão do eixo; x2Field é o segundo agrupador (a dimensão das séries/cor). Use para dados em formato longo — uma linha por combinação (xField, x2Field, valor). O valor plotado é yFields[0].field. Equivale a passar várias yFields (formato largo).

  c.x2Field = 'region';
  c.yFields = [{ field: 'sales' }];
  c.data = [

Meta global — overallTarget

Meta única que vale para todos os registros, desenhada como linha de referência atravessando o gráfico (horizontal nas barras verticais; vertical nas horizontais). A meta entra no domínio do eixo, então a linha sempre aparece. 

<!-- Import (no <head>) -->
<script src="[AprisoScripts]/WebComponents/granado-chart-bar.js"></script>

<granado-chart-bar id="d-ot" title="Vendas (meta 200)" show-values="true"></granado-chart-bar>
<script>
  var c = document.getElementById('d-ot');
  c.xField = 'month';
  c.yFields = [{ field: 'sales', label: 'Vendas' }];
  c.overallTarget = { value: 200, label: 'Meta 200' };
  c.data = [
    { month: 'Jan', sales: 120 }, { month: 'Fev', sales: 180 }, { month: 'Mar', sales: 150 },
    { month: 'Abr', sales: 220 }, { month: 'Mai', sales: 200 }, { month: 'Jun', sales: 260 }
  ];
</script>

Clique & seleção — bar-click

Cada barra é clicável: ela fica destacada e as demais esmaecem; clicar de novo na mesma barra volta tudo ao normal (toggle). O evento bar-click devolve os valores da barra e de toda a categoria. Clique nas barras abaixo:

— clique numa barra —
<!-- Import (no <head>) -->
<script src="[AprisoScripts]/WebComponents/granado-chart-bar.js"></script>

<granado-chart-bar id="d-click" type="grouped" title="Clique numa barra"></granado-chart-bar>
<div id="d-click-out">— clique numa barra —</div>
<script>
  var c = document.getElementById('d-click');
  c.xField = 'month';
  c.yFields = [{ field: 'sales', label: 'Vendas' }, { field: 'target', label: 'Meta' }];
  c.data = [
    { month: 'Jan', sales: 120, target: 150 }, { month: 'Fev', sales: 180, target: 160 },
    { month: 'Mar', sales: 150, target: 170 }, { month: 'Abr', sales: 220, target: 190 }
  ];
  c.addEventListener('bar-click', function (ev) {
    var d = ev.detail;
    var out = document.getElementById('d-click-out');
    if (!out) return;
    if (!d.selected) { out.textContent = '— seleção removida —'; return; }
    out.textContent = '▶ ' + d.category + ' · ' + d.series + ' = ' + d.value +
      '  |  categoria: ' + JSON.stringify(d.categoryValues);
  });
</script>

Atributos / propriedades

NomeTipoDefaultDescrição
dataarray / JSON[]Objetos com os dados. Em JS use .data. Categorias (x) repetidas são somadas.
x-fieldstring—Chave do eixo de categorias. Em JS .xField.
y-fieldsarray / JSON[]Séries (campos na tabela abaixo). Em JS .yFields.
typestring"simple"simple · grouped · stacked · stacked100 · target.
x2-fieldstring—2º agrupador (séries) p/ formato longo. Em JS .x2Field.
overall-targetnum / obj / array—Meta global (linha de referência). Em JS .overallTarget.
orientationstring"vertical"vertical ou horizontal.
titlestring—Título acima do gráfico (entra no PNG).
show-legendbooleantrueLegenda p/ ≥2 séries.
show-gridbooleantrueLinhas de grade.
show-valuesbooleanfalseValor na ponta de cada barra.
show-tooltipbooleantrueTooltip no hover.
animatedbooleantrueAnimação de entrada.
show-exportbooleantrueBotões ⬇ PNG / ⬇ CSV.
export-positionstring"top-right"top-right · top-left · bottom-right · bottom-left.
heightnumber320Altura em px.
widthnumber / —responsivoNúmero = px fixo; ausente = 100% (ResizeObserver).

Campos de cada série (yFields[i]) — só field é obrigatório

CampoTipoDescrição
fieldstringChave do valor no objeto de data (obrigatório).
labelstringNome exibido na legenda/tooltip.
colorstringCor da série (default: paleta Granado, ordem fixa).
formatterfunção (v)→strFormata o valor exibido (rótulo/tooltip).
tooltipFormatterfunção (ctx)→htmlHTML do tooltip. ctx: {category, series, field, value, percent, index}.
sortnumberOrdem de renderização das séries (formato largo).
barWidthnumberLargura máx. da barra dessa série (px).
borderRadiusnumberArredondamento das pontas (default 4).
opacitynumberOpacidade da barra (0–1).
barRolestringdefault · dashed · line.

Evento & métodos

NomeDescrição
bar-clickEvento no clique de uma barra. detail: { category, series, field, value, index }.
.exportPNG(nome?, escala?)Baixa a imagem .png (escala default 2). Inclui título + legenda.
.exportCSV(nome?)Baixa os dados como tabela .csv (separador ; + BOM UTF-8).

Notas

  • type × séries: type só define o layout. As séries vêm das yFields (largo) ou do x2Field (longo).
  • Soma: categorias repetidas são sempre somadas (largo, longo e target).
  • Paleta Granado: cores em ordem fixa (verde · azul · ouro · vermelho · violeta · ouro-claro); passe color por série para sobrepor.
  • Light DOM + inline: sem Shadow DOM e sem stylesheet injetado; SVG self-contained (export sem recursos externos).

Cores por fatia + clique

Cada item de data pode ter color. Clicar numa fatia destaca (toggle) e emite slice-click. A legenda também é clicável.

<!-- Import (no <head>) -->
<script src="[AprisoScripts]/WebComponents/granado-chart-pie.js"></script>

<granado-chart-pie id="pd-click" type="donut" title="Clique numa fatia" show-values="true"></granado-chart-pie>
<script>
  var c = document.getElementById('pd-click');
  c.type = 'donut';
  c.xField = 'status';
  c.valueField = 'qtd';
  c.data = [
    { status: 'OK', qtd: 320, color: '#1F7A3D' },
    { status: 'Alerta', qtd: 60, color: '#9A7520' },
    { status: 'Fora', qtd: 40, color: '#B5342F' }
  ];
  c.tooltipFormatter = function (ctx) {
    return '<b>' + ctx.label + '</b><br>' + ctx.value + ' un · ' + ctx.percent.toFixed(0) + '%';
  };
  c.addEventListener('slice-click', function (ev) {
    console.log('[slice-click]', ev.detail);
  });
</script>
